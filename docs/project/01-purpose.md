# Purpose

> 문제와 경계가 바뀌면 갱신한다.

## One line

**getPersona.md**는 페르소나를 등록·관리·성장시키고, 그 페르소나로 포스팅·댓글·대댓글을 쓰거나 skip하는 **Agent API**다.

## Problem

페르소나 없이 모델을 부르면 글이 계정과 섞이고, 기억을 통째로 넣으면 느리고 새며, 한 번 쓰고 끝나면 다음 글이 나아지지 않는다.

- 등록이 없으면 매 호출마다 정체성을 다시 설명한다.
- 관리가 없으면 보이스·금지·권한이 코드와 프롬프트에 흩어진다.
- 성장이 없으면 경험은 늘어도 다음 retrieve가 정확해지지 않는다.
- 글 종류를 무시하면 댓글이 설명문이 되고 포스팅이 반응이 된다.

## What this product is

- 페르소나의 시스템 오브 레코드: 정체성, 보이스, 경계, 권한, 기억.
- 운영자가 페르소나를 만들고 고치고 키우는 관리면.
- 클라이언트가 호출하는 Agent API. 입력은 페르소나와 글 종류, 출력은 문장 또는 skip.

## What this product is not

- 소셜 게시자, 스케줄러, 피드 수집기, 브라우저 드라이버.
- 일반 챗봇이나 장문 블로그 엔진.
- 페르소나 파일을 통째로 프롬프트에 넣는 래퍼.
- 계정별 `if`가 박힌 엔진.

## Adjacent systems

이 레포가 제품이다. 아래는 같은 워크스페이스에서 관찰된 시스템이며, 재사용 여부는 설계 TASK에서 정한다.

| System | Owns (today) |
|--------|----------------|
| **getPersona.md (this repo)** | 페르소나 수명주기와 Agent API 기획·구현 |
| personaAgent | 기존 쓰기 품질 엔진. 카드 SoR + WriteJob HTTP |
| personaLoop | 수집·스케줄·게시·플랫폼 어댑터. 이 API의 클라이언트가 될 수 있음 |
| llm_wrapper | 모델 호출 게이트웨이 |

## Locked sentence

페르소나가 원본이다. 글은 그 페르소나의 투영이다. API는 문장 또는 skip을 돌려준다. 게시는 본체가 아니다.
