# Product

> 사용자, 글 종류, 시나리오, MVP. 구현이 아님.

## Capabilities

| Capability | Does | Success looks like |
|------------|------|--------------------|
| **등록** | 페르소나를 만든다. 정체성·보이스·경계·권한의 최소 계약 | `persona_id`가 생기고 이후 호출이 이 id만 쓴다 |
| **관리** | 계약을 읽고 고친다. 목록, 조회, 부분 수정, 보관 | 엔진 코드 없이 보이스·금지가 바뀐다 |
| **성장** | 에피소드와 후보를 남기고, 게이트를 지나 LTM이 된다 | 다음 retrieve가 더 정확하다. 폴더가 커지는 것이 아님 |
| **작성** | 페르소나로 `post` / `comment` / `reply`를 쓰거나 skip | 그 사람 말투의 한 줄, 또는  legit skip |

네 능력은 한 제품이다. 쓰기만 있고 등록·성장이 없으면 래퍼다. 등록만 있고 쓰기가 없으면 주소록이다.

## Content kinds

글의 종류다. 소셜 트리도, 품질 그래프도 아니다.

| Kind | Job | 다른 종류로 쓰면 |
|------|-----|------------------|
| `post` | 한 각도의 공개 발화 | 반응문이나 요약이 된다 |
| `comment` | 보이는 원문에 대한 수신 | 설명·조언·작성자 맺음말이 된다 |
| `reply` | 특정 댓글 아래의 관계 이동 | 짧은 댓글이나 빈 감사가 된다 |

원글 → 댓글 → 대댓글 트리는 **입력 맥락**이다. 품질 과정이 아니다. 상황 케이스 표(`if` 원문이 소개면 …)를 제품에 넣지 않는다.

## Users

최종 독자가 아니다. 페르소나를 운영하는 쪽이다.

- **Operator**: 페르소나를 등록·수정하고, 후보와 게이트를 승인한다.
- **Client**: 다른 제품(personaLoop 등)이 Agent API로 쓰기·기억·조회를 호출한다.
- **Schema author**: 카드 종류와 권한 스키마를 확장한다. 엔진에 계정 분기를 넣지 않는다.

정책은 페르소나에 산다. 엔진은 배선이다.

## Quality

점수가 아니다. 종류별 통과 조건이다.

**공통**

- 그 페르소나로 들린다. 계정이 섞이지 않는다.
- 비공개 기억이 밖으로 새지 않는다.
- 채널·언어·길이 제한을 지킨다.
- 확인되지 않은 자기 주장을 하지 않는다.

**post** — 한 각도. 오늘 한 일과 아직 없는 일을 구분한다.

**comment** — 원문 앵커가 보인다. 다른 글에 그대로 옮기면 어색하다. skip이 성공일 수 있다.

**reply** — 그 사람과 그 스레드에서만 성립한다. 관계 기능이 있거나 skip.

정답 문장을 골드에 넣지 않는다. 통과 형태 또는 skip만 적는다.

## Scenarios

1. Operator가 페르소나를 등록한다. 이름, 의도, 보이스, 금지. 이후 호출은 `persona_id`만 쓴다.
2. Operator가 보이스와 경계를 수정한다. 다음 쓰기부터 새 계약이 적용된다.
3. Client가 `post` + brief를 보낸다. API가 문장 또는 skip, 사용한 기억, 후보를 돌려준다.
4. Client가 외부 글에 `comment`를 요청한다. 좁은 계약 + 앵커. 할 말이 없으면 skip.
5. Client가 자기 글 아래 `reply`를 요청한다. 상대 카드 하나 + 스레드.
6. 초안을 수락·거절·수정한다. 후보고 남고, 정체성·보이스·경계는 게이트를 지나야 LTM이 된다.

## MVP

- 페르소나 등록 / 목록 / 조회 / 부분 수정
- 계약 필드: identity, voice, boundaries, permissions
- 성장: `remember` (에피소드·후보) → `promote` (게이트)
- 작성: `post` / `comment` / `reply` → `text` \| `skip`
- 사용한 기억과 run trace
- 쓰기 토큰과 promote 토큰 분리
- 모델 호출은 게이트웨이(llm wrapper 또는 동등) 경유
- HTTP Agent API 하나. CLI/MCP는 같은 코어 위 후속
