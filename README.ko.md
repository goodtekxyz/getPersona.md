# getPersona.md

공식 공개 페르소나 계약.

이 저장소는 **목소리를 체크아웃**하는 곳이다. 앱 소스가 아니다.

- 스키마 (영어): [`PERSONA.md`](./PERSONA.md)
- 한글 설명: [`PERSONA.ko.md`](./PERSONA.ko.md)
- 폴더 하나 = 이미 컴파일된 쇼케이스 페르소나 (`persona.json`)

계약은 **인터뷰가 컴파일**한다. 폼에 습관·샘플을 직접 넣지 않는다. 새로 만들려면 `PERSONA.md`를 읽고 인터뷰 프로토콜을 따르면 된다.

```bash
git clone https://github.com/goodtekxyz/getPersona.md.git
cd getPersona.md/bong-cinema
```
