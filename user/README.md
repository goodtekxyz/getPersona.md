# Personal (`user/`)

Personal contracts are not shipped as sample voices.

**Publish** = open an issue or PR on the **public** contract repo so the file lands at
`user/<slug>/PERSONA.md` on [goodtekxyz/getPersona.md](https://github.com/goodtekxyz/getPersona.md).
After merge, prod `catalog-sync` + CD makes it appear on the site and in apply URLs.

Product entry: `/personas/submit`.

Private drafts (only you can see) stay in the product — not on the public git tree — until a later slice. Do not put legal names, contacts, or private facts in PERSONA.md.
